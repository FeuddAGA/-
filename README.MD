# Random Quote Generator

## Автор
Гатиатулин Тимофей Алексеевич

## Описание
GUI-приложение на Python для генерации случайных цитат.

Функции:
- генерация случайной цитаты;
- фильтрация по автору;
- фильтрация по теме;
- сохранение истории в JSON;
- загрузка истории;
- добавление новых цитат;
- проверка корректности ввода.

## Использование
1. Запустить `main.py`
2. Выбрать фильтр (необязательно)
3. Нажать кнопку **«Сгенерировать цитату»**
4. История отображается в списке.
5. Можно добавлять собственные цитаты.

## Возможные тесты
- Проверка генерации случайной цитаты
- Проверка фильтрации
- Проверка JSON сохранения
- Проверка пустого ввода
